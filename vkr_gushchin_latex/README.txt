# ВКР LaTeX-проект

Тема:
**Глубокие нейросетевые модели в задачах прогнозирования и детекции аномалий в климатических данных**

Автор: Гущин Станислав Алексеевич  
Научный руководитель: Горшенин Андрей Константинович  
Год: 2026

## Состав
- `main.tex` — главный файл проекта
- `chapters/` — главы ВКР
- `references.bib` — библиография
- `main.pdf` — собранная версия

## Сборка
Рекомендуемая последовательность:
1. `lualatex main.tex`
2. `biber main`
3. `lualatex main.tex`
4. `lualatex main.tex`

## Важное замечание
В проект включён рабочий титульный лист. Перед финальной сдачей его нужно сверить с актуальным шаблоном факультета/кафедры.

Примечание по шрифтам: Tinos заменен на автоматический выбор Times New Roman / CMU Serif / DejaVu Serif, чтобы проект компилировался в MiKTeX без установки Tinos.
